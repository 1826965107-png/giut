看什么

  1. 车厢：正常车是原地铁车厢，座椅/立柱/扶手/门缝光都在；门洞对得上，中门开后能走到步道
  2. 步道手电：门外靠墙一只实体手电（不埋地、不悬空），拾取前 F 无效、HUD 显示「未拾取」
  3. 隧道：单一走向的暗隧道，步道比轨槽高，靠墙管束与支架、环肋按 6m 周期重复
  4. 接缝：走到 z≈−48 时同朝向平移 84m 回起点段；画面不黑、不转镜、不停步，缝两侧几何/材质/UV 与灯一致
  5. 回返落点：落点朝前看不到列车（雾与手电有效距离之外），继续走近才慢慢显形
  6. 异变后的车：仍是同一节车厢，但锈蚀/老化，板材轻微鼓曲、窗框错位、扶手倾斜、车顶局部下垂；8 个真窗洞 + 低透明旧玻璃
  7. 可玩性：门净宽 ≥1.1m、中心过道净宽 ≥1.0m、可走净高 ≥2.15m；吊板低边不许被跳跃穿头
  8. 拾取物：电池在敞开座椅旁的收纳架上，钥匙在驾驶端设备托盘上；拿齐后阶段结束但不结算

声音自查（真实游玩时）

  • 跨缝必须没有额外声音：缝边来回走 W/S 不应出现吱嘎叠加；跨缝瞬间只有持续的环境风噪
  • 拾手电、开中门、拾电池、拾钥匙各有一次性提示音，不重复触发
  • 暂停 / 失锁 / 重开都不应出现声音堆积或残留

走一遍（真实流程）

  • 进关后先在车内转身对中门 → E 开门下车 → 门口步道拾手电（E）→ F 开灯
  • 沿步道一直向前（同朝向）走约 48m → 无感跨缝 → 继续向前 36m 才重新看到列车（已异变）
  • 回到中门进车 → 座椅旁收纳架取电池 → 驾驶端托盘取钥匙 → 提示变为「继续探索」，不通关
  • 按 R 完整复位（手电、门、电池、钥匙、异变全部回到初始），可再走一遍
