# L37 淋浴区返修设计与验收

用户实图：`C:/Users/18269/AppData/Local/Temp/codex-clipboard-944eb108-a7c5-4b10-a80b-59191f27a271.png`。前排阻挡后排、透明隔板不能提供私密性。先前验收只确认隔间板件/通路穿过整个房间，未验证每间独立可达与遮挡，结论不足。

## 定稿方向

- 两侧淋浴房各保留4间，共8间。取消同向前后串排，改沿北侧长墙（z约2）单排并列；保持现有更衣→淋浴→湿区的房间和门洞关系。
- 各间外侧共享贯通走道，净宽目标至少1.25m。各间均直接从走道进入，不经另一间，也不绕到夹缝里。
- 各间使用完整不透明隔板（约2.1m高），加前挡板与L形入口回墙。入口净宽至少1.0m，转身区能容纳实际玩家碰撞圆。正面与斜向公共走道视线均被挡住；不能用透明玻璃冒充隐私，也不能用没有碰撞的板件假遮挡。
- 入口采用固定错位屏风；能沿L形真实走入使用点并走出，保留日常使用逻辑。浴位在后部湿区，花洒/阀门/管件贴实际后墙。石材、暖白板面、深铜灰五金沿用现有会所材质家族，地面连续、排水明确。
- 几何候选：每间外包宽2.4m、深2.3m，z约[2.25,4.55]；西侧中心x约[-26.3,-23.65,-21.0,-18.35]，东侧镜像。公共走道z约[4.62,5.88]；现有更衣门x约±12.8不被占，靠湿区出口端留擦身/过渡空间。最终以真实网格、墙厚和碰撞净距校正，不可将候选尺寸直接当已验收尺寸。
- L形内部：入口靠一侧，前屏遮住另一侧浴位；回墙从前屏向内延伸约0.95m，入口侧约1.0m净宽，绕过回墙北端后进入淋浴位置。东西镜像。浴位前不另摆一间同向隔间。

## 必须验证

1. 使用真实updatePlayer逐间从本侧更衣入口→公共走道→各间浴位→退出走道→湿区出口。共8间，不能只走房间中心或只测寻路图；记录最大单帧位移、到达位置及失败原因。
2. 独立可达负对照：临时封掉任意一间的入口，其余各间仍可由公共走道到达；封一间不能挡整个后排。
3. 隐私：在实际公共走道多个前/斜角眼位，对各间浴位胸部与头部区域采样射线，应先命中真实不透明遮挡面；移除前屏/回墙后至少一个负对照应暴露浴位。透明材质不算隐私屏。
4. 网格与碰撞同源，板脚落地，花洒支撑与墙面吻合，入口和走道净宽按完整包围盒计算。不得仅靠“生成三块板”或声明尺寸通过。
5. 截图：西侧整排、东侧整排、公共走道看入口、进入一间后的花洒/排水近景。正式灯光、真实WebGL；确认镜头未在墙里、图里能看到被验对象。
6. DSH自行运行受影响L37/总L12、props、plan、syntax检查，最后同步online并--check；保存新日志并回传实际命令/退出码。Node渲染桩与真实WebGL分别说明。Codex只读程序与测试，审查画面。
