# 第一、二关地图与怪物精度改造

## 目标与职责

用户要求提升前两关地图与怪物的制作精度，第二关地图优先。Codex 负责本设计、只读审查与画面验收；DSH 负责程序实现、运行测试、修复以及提交测试证据。本次采用用户指定的 DeepSeek 登录账号渠道 DS V4.1 Flash；已在实时目录核对并选定 deepseek-account/deepseek-flash（显示名 DeepSeek-V4.1-Flash）。

## 现状依据

- 第一关是 86×48m 外壳中的长直主廊与少量侧室；大量面积没有空间叙事，墙面、灯具和家具缺乏近看细节。
- 第二关为 48×36m 单一高度大盒子，只有两道大开口纵向隔墙。六个目标全部集中在两座泳池中，空间与路线单调。
- 黑影与池中人共用近似骨架，黑影主要靠纯黑材质和红眼区分。黑影追逐直接朝玩家位移，没有遵守墙体碰撞。
- 漂浮物背视漂移不限制在所属水池，可能漂上岸或穿墙；拾取仅比较水平距离，缺少遮挡和高度检查。

## 第一关：可辨认的回环迷宫

保留黄墙、潮湿地毯、低天花和三保险丝核心。保留出生点 (-144,0) 及东端出口，所有目标可真实步行到达。

1. 接待区：靠近出生点的办公前室，接待台、黄门、倒伏椅子、墙上旧指引作为第一次辨认方向的地标。用门框与墙厚形成真实阈值。
2. 档案区：中段北侧，以错开的墙段、档案柜和较密天花骨架形成压迫感；可经侧廊绕回主路。柜子按真实高度和轮廓碰撞。
3. 配电区：东段以配电柜、裸露管线和维修灯区分；第三枚保险丝所在支路有回路可逃，不能是无处退让的怪物陷阱。
4. 南侧空办公室作为第二条回路，形成至少两个可验证的闭合行走环路。主路线避免从出生点一眼望穿出口，不靠塞满随机短墙制造迷宫。

常用通道净宽至少 1.4m，关键转弯留出玩家半径的余量。三枚保险丝分别落在可辨识区域，桌面或设备托座承载，不悬空旋转成占位方块。通过局部灯色和建筑细节引路，保留迷失感。

提高近景工艺：有厚度的踢脚、墙纸接缝、灯盘边框、天花拼缝、门套、通风百叶、插座、柜门把手与少量真实尺度水渍。大细节服务构图，小细节合批。黄灰、焦褐为主，低饱和维修绿只做地标。允许看清近处材质和房间关系，不能靠极低曝光遮丑。

## 第二关：带双环路的公共浴场

空间安排优先于堆物件。可扩展外壳为 x=-28..30、z=-28..24，并同步地板、外墙、顶棚、碰撞和光照边界；若用等效布局，必须满足以下拓扑与体验。

- 南侧入口缓冲区：z≈14..24，狭一点的更衣前厅打开到主池大厅，产生先收后放的第一视角。入口和重生点看得到清晰岸边与中央水面，不能落在墙体或池中。
- 中央主池厅：保留 25×12m 主池位置与深水体验。泳道比例调整为六条约 2m 宽的泳道，文档不再称八道标准竞赛池。完整绕池步道、池沿排水、深度标识、出发台与扶梯形成构图。近看池沿具有合理收口。
- 西侧更衣淋浴区：x≈-28..-16，有分段更衣柜、长凳、淋浴花洒、地漏，分隔过大的长条空间；设置南北两个入口，使其成为绕行支线。旧设施需一并调整，禁止新旧墙或装饰穿插。
- 北侧浅水回声室：z≈-28..-16，通过有墙厚的门洞与主池连接。新浅池可位于 x=-12..-4、z=-25..-19，水深约 0.5m，有真正可走的缓台。较低的顶棚、重复柱门和冷色水光与主厅形成节奏差异。
- 东侧训练池与设备区：训练池保留在 x≈14..22；用柱廊、局部墙和观察窗形成可见但不立即可达的空间，设备间有泵组、管线、压力表与柜体。南北联通，构成另一条环路。

路线应连通为“入口 → 主池 → 北回声室 → 东训练池 → 入口”，另有“入口 → 西更衣区 → 北廊 → 主池”的回路。主体不可退化为只有装饰拱门的空大厅；至少有四个在正常玩家视高下可辨认、通过真实墙体分隔的空间。

六个漂浮物分到主池、训练池、浅水回声池各两个，总数和种类仍为四鸭二圈。每池有可靠进出方式；台阶单级高度不超过现有控制器的 0.62m 限制，优先采用更平缓多级台阶。模型台阶与 groundAt 来自同一份数据。漂移必须限制在自己的水体内，不能跨墙或漂到干地。

美学：瓷白与失绿的青色为主，锈色只出现在排水与五金接缝；避免整墙随机脏污。主厅用连续梁与重复灯具形成秩序，回声室采用更低更密的重复结构，设备区少量暖色维修灯。几何和贴图使用米制周期，墙地砖对缝，避免纹理在薄边上被拉长。水面保持室内静水，怪物的扰动作为例外。

## 怪物身份与公平性

### 第一关：黑影

- 从 refs/lurker-ref.png 的驼背、长臂、前伸头颈提取轮廓；高约 2.2m，手接近膝下，左右肩与步态略不对称。躯干、骨盆、关节连续，不呈串珠或互相脱开的几何体。
- 炭黑湿织物或皮质感，侧光能读出轮廓，眼部为细小暗红反光，降低自发光灯泡感，不依赖新增动态灯制造存在感。
- 凝视、发现、追逐、搜寻、消退应有可读的节奏。保留三保险丝带来的追逐升级，不隔墙触发凝视惊吓或抓取。出现点不压在玩家脚下、墙中或出口门口。
- 追逐必须沿可行路径绕墙，有限频率重规划，移动分步碰撞。丢失视线时追向最后目击位置，不能穿过封闭墙追踪。玩家能依靠环路甩开它。

### 第二关：池中人

- 与黑影形成独立轮廓：灰白浸水皮肤、凹陷眼窝、塌肩与偏斜头部，湿发为有层次的发束，手指与肘膝连续；避免照搬同一模型只换颜色。
- 站立时通过极轻的呼吸、手指与头部延迟响应维持不安；游动时躯干转为合理姿态，手臂和腿有不同节拍，发束有滞后摆动。模型不得穿过池壁或水面产生遮挡闪烁。
- 主池是它的主要活动区。停电只在有效水下点之间转移，不能闪到玩家接触距离。出场先有可辨认水声/水纹，保留反应窗口；上岸后不在干地追逐。
- 受击/惊吓后设冷却，重生在安全入口，保留已收集进度。所有攻击和拾取遵守距离、真实遮挡与高度。
- 更衣区人影可以作为短暂事件保留，但要降低随机频率并统一冷却，不能连续惩罚刚复位的玩家。

主入口仍为 backrooms-pool.html；CDN 版用现有同步工具生成。可提取前两关专用模块，但避免无必要重写宿主、第三关与第四关。不得破坏三关/四关现有行为、预览不写档、R 复位和全流程关卡衔接。所有需要随关卡隐藏的灯与模型应有明确归属，新增灯数量有固定预算，禁止逐帧创建材质/网格/灯。小部件复用几何与材质并合批，新增水面保持有限反射开销。
