# 前两关重构：紧凑后室与真实温泉会所

状态：2026-11-04 新一轮完整改造设计；取代上一版“保留大外壳加隔墙”的布局要求。Codex 负责研究、规划、美术资产与审查，DSH 负责全部程序、集成、测试。保留现有成果与后两关，不提交或推送。

## 研究来源与设计推论

1. 4a Architekten / Salinarium Therme：既有游泳设施旁增加温泉、冷热池、桑拿与休息空间，采用连续房间序列和节制的木、石、陶瓷材料、建筑照明。建筑师项目和地面层平面入口：https://www.4a-architekten.de/projekte/salinarium-therme-bad-duerkheim
2. Behnisch / Thermal Römerbad：明确的主浴场与围绕中庭组织的桑拿、休息及服务带。建筑师原始图册含分层平面：https://behnisch.com/content/2-work/1-projects/0-0262/0262_thermal-roemerbad_e.pdf
3. Sixseven Studio / Yunomori Sathorn：接待与庭院作为过渡，泡汤区采用统一表面节奏、天然石材与间接光，轻木、米白、灰色统一家具。建筑师供稿及二、三层轴测：https://www.archdaily.com/958075/yunomori-onsen-and-spa-sathorn-sixseven-studio

以下为适配恐怖游戏的原创重组，不是直接复制真实建筑：明确干区→更衣→淋浴→湿区，游泳与泡汤相邻但功能可辨，后勤独立，回路有方向与用途。美术统一不等于所有面使用同一张图片。

## 第一关：删掉无用途面积，形成可记忆的设施后勤前场

- 保留黄色后室、3 枚保险丝、手电、黑影追击和进入第二关的核心。允许移动出口、房间、目标、重生点及缩小边界，旧绝对坐标测试不是设计约束。尽量保留西侧出生位置 (-144,0)，与后两关空间偏移隔离。
- 总外包范围目标约 42×24m，上限 44×26m；由原 86×48m 大幅收紧。实际可走面积控制在约 700–850m²，优先压缩无目的走廊。剩余区域封成实心后勤建筑边界，不留下无用空房。
- 6 个可辨识区域：值班接待/停用访客厅、员工更衣与休息、票务档案、布草整理/洗衣后勤、维修配电、通往浴场的服务前室。不要再添加“空办公室 A/B/C”。
- 主序列：出生接待（看见失电配电图）→员工区第1枚（学习看/取）→档案区第2枚（短视线、发现黑影）→洗衣后勤通向配电第3枚（压力段）→服务前室出口。两个短回环接回中央节点，支路能避敌、看见另一方向或提前辨认下一目标。
- 每一房间必须在设计表写出：目标/风险/线索/捷径/视觉揭示中至少一项，纯空房不通过。盲支路若无明确奖励或叙事，缩短或取消。避免长距离重复搬运与只靠随机墙制造迷路。
- 走廊 1.6–2.2m，主要节点 3–4m；天花 2.7–3.0m，通过门洞与低吊顶压缩/释放。黑影可行路线与玩家路线一致，至少两处绕行而非环形大操场。
- 场景构图：低柜、布草车、打卡机、老式票柜、透光磨砂隔断、配电箱共同说明这是浴场关闭后的后台。家具按工作关系组合，保持观看距离。旧地标可复用但必须重排，不把全部旧物留在新墙里。

## 第二关：入口可读、干湿顺序正确的温泉会所

建议总体范围约 60×58m（可按实际净空略收缩），南为入口，北为休息回廊。功能组织优先于外包面积，所有子房间围绕实际使用，不再把池子塞进任意格子。

### 必须成立的邻接关系

入口/接待 → 脱鞋储物 → 男女或两组更衣间 → 分隔淋浴/冲洗 → 湿区分配厅。

湿区分配厅右向：25m 游泳池厅；左向：温泉泡池区。泡池区连接桑拿/蒸汽小间、冷水池及静休区。北侧休息回廊连通游泳与温泉两厅，形成第二条可辨识湿区环路。设备/水处理区靠外墙，只以员工门与服务走廊连接，不能成为游客到下一池子的必经之路。

### 建议几何分配（可按净空调整，禁止局部补丁破坏顺序）

- 南入口接待：z≈17..26，中央入口与总导览；西侧为饮水/休息等候，前台后有服务门。入口不直接跌进池沿。
- 两组更衣与淋浴：z≈3..17，以可辨柜列、长凳、洗面台、淋浴隔间形成使用顺序。入口和出口分清，湿区回来也能直觉找到淋浴及更衣。隐私转折不靠闭塞迷宫。
- 东游泳厅：主池约 x=8..18、z=-24..1，25×10m，5 条 2m 泳道；围池步道约 2.2–3m，额外空间只用于靠窗躺椅、观察位或通行节点，不留空阔无物大厅。池深、台阶、泳道数量与标识必须据实际数据生成。
- 西温泉厅：约 x=-26..-2、z=-27..3。至少一座温热主汤池（约10×8m，水深约0.85–1.0m）、一座安静小汤池（约6×6m，浅水/坐凳）、一座冷水池（约3×3m）及小型桑拿/蒸汽间。温泉池有入池阶梯、坐台、温度牌、回水口和轻微热气，不能只是原训练池改名字。
- 北静休廊：带可见光庭/磨砂高窗，连接两厅；温泉侧可坐凳、躺椅及壁龛，保留清晰出口方向。无需新增真实户外世界。
- 后勤设备区贴外缘；合理泵组、管线、检修口，不在游客主线上布随机机器。
- 仍为 6 个主要收集目标，游泳池/温热主池/静汤池各2个，冷水池不强制收集。3 枚保险丝和6个收集物数量不随布局任意增加；可将鸭子/救生圈做成更精致的真实物件，避免 UI 地标漂浮。

## 统一美术与真实构造

- 第二关只用一套材料家族：暖灰米色防滑石砖地、暖白矿物墙面、灰绿石质小砖池内、烟熏浅木用于更衣/桑拿/家具、深铜灰金属用于五金。湿干区通过构造、铺装尺度、光色区分，禁止每房随机更换色相和图片。
- 第一关保持同设施的旧后台语汇：亚麻黄细墙纸、深橄榄褐低绒地毯，少量旧木、磨砂玻璃、灰绿烤漆。采用统一门套、踢脚与细节尺度。
- Codex 将提供新版可平铺漫反射资产；先用最终文件名作接口，资产到齐后再验收：`textures/l12-v2-spa-floor.png`（4×4块石砖，整张2.4m）、`l12-v2-spa-plaster.png`（连续矿物墙，整张2m）、`l12-v2-pool-mosaic.png`（8×8小砖，整张0.4m）、`l12-v2-wallpaper.png`（连续黄麻织墙纸，整张2m）、`l12-v2-carpet.png`（低绒地毯，整张2m）。由DSH复制/集成生成资产，旧文件保留。
- 使用真实世界米制 UV；同材质跨房间、拆墙段保持相位/比例。不要把污渍/颜色纹理强制派生高强度浮雕。石材粗糙度0.75–0.9、金属度0、低clearcoat；墙面法线0.08–0.18、地面0.08–0.15。池内釉面可有限反光。
- 天花改为可读的矿物/木格栅构造与嵌入灯，后台用旧声学板；不得用纯黑面把吊顶缝、墙头、设备隐藏掉。基底照明足以读近处材质，重点灯和窗光组织方向。
- 灯带有槽、灯盘有壳、横梁有支撑、门洞有门楣和内衬、玻璃窗上下有真实墙体、池沿排水格栅有适合水环境的收边。标识统一成一套固定位置的墙牌/地贴，真实宽度，不与柱脚、门扇、设备相交。
- 黑影和池中人保留不同轮廓与既有公平 AI，消除明显关节缝、塑料高光、锥发倒置；在新灯光中验收前侧近景，不用改变颜色冒充完成重建。
- 轻微蒸汽、反射与柔和光束用于温泉氛围，不能用白雾或过曝遮住几何；材质/家具实例化，灯具不逐帧新增。不要把后两关材质或模型改坏。
